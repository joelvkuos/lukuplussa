# Luku⁺

Mobiilisovellus lukemisen tueksi ja termien harjoitteluun. Rakennettu React Native:llä ja Expo:lla.

## Ominaisuudet

- **Koti**: Sitaatteja, vaihtuvat joka kerta kun sivulle mennään
- **Terminologia**: Selaa, etsi ja lisää omia termejä 30 valmiiksi lisätyn termin rinnalle
- **Muistikortit**: Harjoittele termejä, seuraa edistymistäsi
- **Kirjasto**: Lisää kirjoja, muokkaa ja poista niitä

## Teknologia

- **React Native** - Mobiilikehitys
- **Expo** - Kehitysalusta
- **TypeScript** - Tyyppiturvallisuus
- **AsyncStorage** - Paikallinen tietojen säilytys
- **Expo Camera** - Kameran käyttö
